# fx-intraday — デイトレ2系統の直近アクション

## 前提

- 2系統とも**試験運転中**（config の `試験運転: true`）。提示のたびにその旨を添える。
- 両系統とも利確指値を置く設計（OCO）。日足2システムとはここが違う。
- 判定は15分ごと。確定バーが更新された回だけアクションが出る。

## 手順

### 1. 直近のアクションを拾う

```bash
python3 scripts/fx_fetch.py --intraday --since-min 70
```

`--since-min` は「何分前までを対象にするか」。ルーティンの実行間隔＋10分にする
（毎時実行なら70）。クラウドからは未通知キューを既読化できないため、
**時刻の窓で重複通知を防いでいる**。窓の外のidを拾い直さないこと。

返る各要素: `システム` `時刻` `アクション` `要旨` `id` `pips記載`

### 2. アクションが無い場合

「直近70分にデイトレのアクションはありません」と1行で返す。
ルーティン実行時は**通知を送らない**（沈黙する）。

### 3. アクションがある場合 — 発注カードを出す

```bash
python3 scripts/fx_fetch.py --intraday-card 2H     # または 15m
```

指示書本文の `◆ 発注カード` 以降をそのまま提示する。カードの「幅（pips）」欄は
**利確幅 → 損切り幅**の順で、新規建てなら次の形で入っている。

```
  利確幅      : 約136 pips／+27,120円（想定約定159.456 → 利確158.100）
  損切り幅    : 約78 pips／-15,680円（想定約定159.456 → 逆指値160.240）
  RR          : 1.73（利確幅 ÷ 損切り幅）
```

新規建てのときは**必ず**次を添える。

> 成行で建てた直後に、決済OCO（逆指値＋利確指値）を必ずセットしてください。

### 4. 通知（ルーティンから呼ばれた場合）

PushNotification（status: proactive）を1本。文面は `要旨` をそのまま使う。

- 例: `デイトレ15分: 新規売 20,000通貨・逆指値160.240円（損切り78pips／利確136pips）`
- `pips記載` が `false`（旧版エンジンの回）なら、pipsを補わずそのまま送り、
  末尾に「※幅pipsは旧版のため未記載」と付ける。

複数系統が同時に出た場合は1本にまとめる（2回鳴らさない）。

## やってはいけないこと

- pips幅・ロット・OCOのレートを自分で計算する
- 「試験運転中」の但し書きを落とす
- 窓の外の古いアクションを再通知する
- アクションが無いのに定時通知を鳴らす
