# fx-now — 4システムの現況一覧

## 手順

### 1. 現況を取得する

```bash
python3 scripts/fx_fetch.py --status
```

返るJSONの構造:

- `システム.<名称>` … `ポジション`(1=買/-1=売/0=無) `建値` `数量` `決済逆指値`
  `決済指値(利確)` `建玉日` `鮮度`
- `警告` … 鮮度切れなどの配列。空でなければ**必ず先頭で伝える**

### 2. 表で提示する

| 系統 | 建玉 | 建値 | 逆指値 | 利確 | 更新 |
|---|---|---|---|---|---|
| 長期トレンド | 売 2,000 | 157.272 | 161.427 | — | （state.json） |
| デイトレ15分 | 買 7,000 | 159.491 | 159.077 | 160.318 | 06:05 |

- 日足2システムの利確は必ず「—（利確目標を置かない設計）」。
- デイトレ2系統に `試験運転: true` が付いていれば「試験運転中」と明記する。

### 3. 「あと何pips」を聞かれたら

**自分で引き算しない。** 各系統の最新指示書に書かれている距離を転記する。

```bash
python3 scripts/fx_fetch.py --intraday-card 2H     # デイトレ複合時間軸
python3 scripts/fx_fetch.py --intraday-card 15m    # デイトレ15分
python3 scripts/fx_fetch.py --card                 # 日足2システム
```

指示書の【継続】行、または発注カードの「現値から」行に、
`現値159.456円 → 逆指値まで 38 pips／利確まで 86 pips` の形で入っている。これを使う。

どうしても指示書に距離が載っていない場合（旧版エンジンが生成した回）は、
「この回の指示書には距離の記載がありません」と述べ、レートのみ示す。

### 4. 鮮度を必ず添える

- `鮮度: 最新` … そのまま提示してよい
- `鮮度: 休場中` … 「市場休場中のため更新は止まっています」と添える
- `鮮度: 古い` … **先頭で警告**。「N分間更新がありません。以下は古い値です」と明記し、
  古い数字を現在値のように扱わない

## やってはいけないこと

- 建値と逆指値の差を自分で計算してpipsとして提示する
- 含み損益を自分で計算する（指示書の「現在の建玉損益」欄を転記する）
- 鮮度切れを黙って提示する
