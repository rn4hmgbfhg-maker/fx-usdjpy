# FX ドル円 自動売買スキーム（MATRIX TRADER運用版・2システム構成）

売買判定〜注文指示書の作成までを完全自動化し、発注のみMATRIX TRADERで手動で行う
**半自動方式**のドル円運用スキーム。
（JFXは公式FAQでEA=自動売買プログラムの利用を禁止しているため、自動発注は行わない設計）

**2系統のシグナル**（パラメータは研究により日々進化・config.jsonが正）:
- **長期トレンド** … ドンチャン40/10・ATR×3.5・リスク1%。大トレンドを数週間〜数か月保有
- **短期スイング** … ドンチャン20/8・ATR×1.5・リスク0.5%。数日〜2週間の波で回転（年18回程度）

**指標イベント勘案**: 毎朝、今後24時間の高重要度イベント（FOMC・雇用統計・日銀会合等）を
自動取得し、該当日は新規建てを自動見送り。指示書にイベント一覧を表示。

さらに毎朝8時の配信後に**日次研究（パラメータ探索）**が走り、頑健性基準を満たした
場合のみ戦略パラメータが自動進化する。運用状況はGoogle Driveの
**「マイドライブ/FXドル円自動売買」**フォルダの運用ダッシュボード(xlsx)に毎日自動反映される。

## 週次ペア研究（毎週土曜9時・自動）

スケジュールタスク `fx-pair-research-weekly` が主要11通貨ペアの15年検証
（現行2システム適用＋上位ペアの専用最適化）を自動実行し、
「ドル円優位継続／接近／要注目」を判定してスマホへ週次報告する。
結果は `results/pair_scan.csv`（最新）・`pair_scan_log.csv`（履歴）と
ダッシュボードの「ペア研究」シートに反映。ペアの乗換え・追加は自動では行わず、
「要注目」判定が出た時にユーザーが判断する。

## 日次研究（スキーム自動進化）

毎朝8時の配信後に15年データでパラメータ探索（315通りの検証）を行い、
**全ての頑健性ゲート**（前半・後半両期間でPF≥1.3／取引数≥60／最大DD≥-12%／
現行の頑健スコア比1.05倍以上）を満たした候補だけが `config.json` を書き換えて
翌朝から適用される。単純な成績最大化（カーブフィッティング）による劣化を防ぐ設計。
全探索結果は `research_log.csv` とダッシュボードの「研究ログ」シートに記録される。

## 毎日の流れ（3段階配信・所要約5分）

スケジュールタスクが平日の朝に3回、シグナルをスマホへプッシュ配信する:

| 時刻(実起動) | 段階 | 内容 |
|---|---|---|
| 6:06 | 【速報①】 | 参考配信。モデル状態は更新しない |
| 7:06 | 【速報②】 | 参考配信。速報①からの変化有無を明記 |
| 8:06 | 【最終確定】 | **正式な注文指示**。state.jsonを更新。発注はこれに従う |

1. 8時の【最終確定】通知と指示書（`results/orders/日付_指示_確定.txt`）を確認
2. 「新規」ならMATRIX TRADERで **IFO注文**（新規成行＋決済逆指値を同時セット）
3. 「ストップ変更」なら決済逆指値を指示水準へ変更
4. 「待機/継続」なら何もしない

※米国冬時間期（11月〜3月）は日足確定が朝7時のため、6時の速報①は未確定バーの暫定値。
※手動実行する場合: `python3 src/signal_engine.py`（既定=最終確定）、`--stage 1/2` で速報。

## 自動実行（設定済み）

Claude Codeのスケジュールタスク `fx-usdjpy-signal-morning`（cron: `0 6,7,8 * * 1-5`）。
Claudeアプリが起動していることが実行条件（閉じていた場合は次回起動時に実行）。
タスクはサイドバーの「Scheduled」から管理できる。

## 設定変更

`config.json`:
- `口座資金_円` … 月1回、MATRIX TRADERの実際の口座残高に合わせて更新
- `1トレードのリスク率` … 既定0.01（1%）。実運用が安定するまで引き上げない
- `実効レバレッジ上限` … 既定3.0
- `ATRストップ係数` … 既定3.0（設計書の検証パラメータ）

## バックテストの再実行

```bash
python3 src/run_backtest.py
```

## 注意（必読）

- 発注は必ず本人がMATRIX TRADER上で行うこと（JFXは自動売買禁止）
- ストップ（逆指値）のない建玉を持たないこと
- 口座資産がピークから20%減ったら新規建てを停止（キルスイッチ）
- 過去の検証結果は将来の成果を保証しない。余裕資金で運用すること
