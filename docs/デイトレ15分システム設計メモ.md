# デイトレ15分システム（第4システム）設計メモ

2026-08-13 新設。ユーザー指示「デイトレ専用のシグナルを作成。テクニカルと
ファンダメンタル、世界の信頼できるシグナルを駆使して完成度100%。15分単位で
確認・監視してシグナルを出す」に基づく。

## 全体像

- **データ**: `data/usdjpy_15m.csv`（Yahoo 15分足・直近60日を毎回マージして
  履歴を育成）＋ `data/usdjpy_15m_hist.csv`（Dukascopy BID 1分足を15分足に
  リサンプルした約3年の長期履歴・バックテスト用）。`src/data_fetch_15m.py`。
- **戦略**: `src/strategies_15m.py` に世界のデイトレ実務で実績のある5系統を実装。
  1. 15分ドンチャンブレイク＋上位足フィルタ（タートルズ系・既存3システムと同族）
  2. オープニングレンジブレイクアウト（Toby Crabel系。東京/ロンドン）
  3. ロンドンのアジアレンジブレイク（欧州勢参入の定番。USDJPYで古典的に有効）
  4. EMAトレンド＋短期RSI押し目（Larry Connors系プルバック）
  5. BBスクイーズブレイク（ボラティリティサイクル）
  補助: TradingView型テクニカル合議（MA群＋オシレーター群の多数決）を
  15分足・1時間足で算出し指示書へ併記（参考表示・ゲートはしない）。
- **確認フィルタ**（★2026-08-14追加・`src/tech_filters.py`・2H系と共用）:
  性質の異なる5系統のテクニカルでドンチャンの新規建てを選別し精度を上げる。
  1. ADX(Wilder)≥閾値 … トレンド相場のみ許可（レンジのダマシ排除・方向不問）
  2. RSIレジーム … RSIが50±マージンで方向一致した時のみ許可
  3. MACD順行 … MACDライン vs シグナルの上下で方向一致のみ許可
  4. MA合議 … EMA/SMA(10〜200)多数決スコアが閾値以上で方向一致のみ許可
  5. ATR分位 … ボラが過去分位以上の拡張局面のみ許可（閑散相場を追わない）
  spec「確認フィルタ」（単体または AND結合リスト）としてconfigパラメータに
  内包され、研究とエンジンが build_signal / entry_mask を共用するため判定は
  常に一致する。手仕舞い（イグジット/ストップ/利確）には関与しない。
  research_15m.py / research_intraday.py が上位候補×9パターンを毎日探索し、
  頑健性ゲート＋現行1.05倍超の時のみ進化採用する。
- **研究**: `src/research_15m.py`。全戦略×パラメータを横断バックテストし、
  頑健性ゲート（前後半PF≥1.10・DD≥-10%・頻度0.3〜4回転/日・取引数≥60）で
  選別。上位候補に利確ATR係数(0/2/3/4)を重ねて最終決定。現行の1.05倍超で
  進化採用（既存2H系research_intradayと同じ思想）。config「デイトレ15分」。
  ★2026-08-13ユーザー指示: 15分足に加え1時間足・4時間足も候補に含める
  （spec「時間足分」15/60/240。セッション系ORB・アジアレンジは15分のみ。
  エンジンは選定戦略の時間足へリサンプルして判定し、起動は15分ごとのまま
  上位足バーの確定を最速検知する）。
- **エンジン**: `src/intraday15_engine.py`。15分ごとに判定し、アクション時のみ
  指示書（`results/intraday15_latest.txt`・`results/orders/intraday15/`）と
  通知（macOS通知＋Gmail SMTP即時メール＋未通知キュー）を出す。
  - 指標イベントゲート: ★5級の45分前から新規建てブロック（events.py）
  - ファンダ併記: fundamental_latest.json のレジーム・翌日予測・次の焦点
    （予測は検証でエッジなしのため表示のみ、発注判定には未使用）
  - 状態: `state_intraday15.json`（指示した建玉のみが正）
- **実行**: launchd `com.ochiai.fx-intraday15`（毎時4/19/34/49分）が
  `src/run_intraday15.py` を起動（リトライ・実行ログ・休場スキップ・--check）。
- **通知経路**（3段構え）:
  1. エンジン自身: macOS通知＋即時メール（（本人アドレス・local_settings.json で設定）宛・シグナル時のみ）
  2. 毎時Claudeタスク fx-usdjpy-intraday: 未通知キューをスマホプッシュで補完
  3. 対話セッション中: persistent Monitorで未通知を検知して即時プッシュ
- **ボード**: dashboard_web.py にデイトレ15分カード・指示書併記・含み損益
  合算・直近の記録（「15分」表記）を追加済み。

## 発注ルール（既存と同一の半自動思想）

- JFX(MATRIX TRADER)はEA禁止 → 判定と指示書まで自動化し発注は本人が手動。
- 新規=成行＋決済OCO（ATRトレイリング逆指値＋目標利確指値）。
- 試験運転中は指示書・通知に【試験運転】を明記。
- リスク率0.3%/トレード・レバ上限1.5倍（第4システムとして控えめ）。

## 既知の注意

- Yahoo 15分足は60日しか遡れないため、長期検証はDukascopy履歴が前提。
  live判定は直近数百本で足りるのでYahooのみで動く。

  再実行すれば続きから取得する（チェックポイント方式）。
