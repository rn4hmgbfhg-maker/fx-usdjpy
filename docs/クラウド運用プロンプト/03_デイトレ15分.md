## ★名称と実体のズレに注意
システム名は「デイトレ15分」だが、2026-08-13の日次研究で採用された**現行戦略の実体は
1時間足ドンチャン24/12・フィルタ無**（研究が15分/1時間/4時間を横断探索した結果、
1時間足が採用された）。したがってクラウド版はYahooの1時間足をそのまま使えば足りる。
現行パラメータ: ATR×3.0・目標利確ATR×6.0・リスク0.3%・レバ上限1.5（採用スコア1.099）。

※将来の研究で**時間足が60分未満へ進化した場合、このスクリプトは使えない**
（Yahooの1時間足からは15分足を復元できない）。その時は `agg_bars()` が明示的に
エラーで止まるので、Mac版かGitHub Actions版（15分足を取得する）へ切り替えること。

## 検証記録（2026-08-16）
- **純リプレイでMac版と完全一致**を確認した。建値159.358円・5,000通貨・最良値159.285円・
  建玉バー 2026-08-15 03:00 のすべてが `state_intraday15.json` と一致
  （目標利確のみ158.350 vs 158.349＝ATRの浮動小数点丸めによる0.001円差）。

- 実欠陥2件（指標カレンダーの429・データ鮮度ガード欠落）は本ファイルでは修正済み。
  詳細は `02_デイトレ複合時間軸2H.md` の表を参照。

## 使い方

### モードB｜ローカル貼付（Macや手元PCのClaudeセッション）
下の「━━ 運用プロンプト ━━」以下を丸ごと貼って送信する。毎時5分すぎを目安に再実行する
（1時間足は毎正時に確定する）。`state_intraday15.json` が読めるなら `SEED_AS_OF`（= `last_bar`）と
`LIVE_STATE`（= `state`）を埋めるとさらに確実。

### モードA｜GitHub Actions（完全クラウド・Mac不要）
`cron: '5 * * * 1-5'`（UTC）で走らせ、出力JSONと状態をリポジトリへコミットする。
**移行の第1号はこのシステムを推奨**（1時間足で判定が軽く、リプレイ精度が実証済みのため）。
手順は `08_GitHubActions移行手順.md` 参照。

### モードC｜WebSearch劣化モード
クラウド既定環境ではYahoo/Forex Factoryが EGRESS_BLOCKED になる。既存 routine
「FXドル円 デイトレ予備判定」（`trig_01Sp1jvcN277EZNbHsNiFaZ2`・cron `35 * * * 1-5`）が
まさにこの代替であり、**すでに有効**。近似チャネル（本日/前日の高安）で
「Macを確認すべきタイミング」だけを知らせる。

FXドル円半自動売買スキームの第4システム「デイトレ15分」（実体は1時間足ドンチャン24/12）の

手順:
1. 下のPythonスクリプトを `fx_intraday15_cloud.py` として保存し、`python3` で実行する
   （標準ライブラリのみ。Yahoo Financeの公開チャートAPIとForex Factoryの公開カレンダーを取得する）。
   - `state_intraday15.json` が手元にあれば `SEED_AS_OF`（= `last_bar`）と
     `LIVE_STATE`（= `state`）を埋めてから実行する。
2. 出力された「■ ドル円 デイトレ15分指示書【クラウド代行】」全文をそのまま提示する。
3. 最終行のJSONを読み、要点を1〜2行に要約してプッシュ通知（status: proactive）を送る:
   - 新規建て: 「【デイトレ15分・要発注】ドル円: 新規売 5,000通貨・成行→OCO（逆指値159.863円／利確158.349円）（試験運転）」
     ※新規は必ず逆指値と目標利確の**両方**を載せる
   - 保有継続: 「【デイトレ15分】売5,000通貨保有中: 逆指値159.705円／利確158.349円を維持。口座と一致するか確認を」
   - `last_event` がストップ決済/利確決済: 「【デイトレ15分】◯◯決済の可能性。約定履歴を確認」
   - `event_block` が true: 末尾に「⚠指標直前のため新規停止中」を付記
   - `stale` が true: 末尾に「⚠データ鮮度不足（休場中なら正常）」を付記し、**新規建ての指示は出さない**
4. 毎時5分すぎに繰り返す（1時間足は毎正時に確定する）。

厳守事項:
- 発注は絶対に自動化しない。JFX（MATRIX TRADER）はEA・自動売買が規約で禁止。
  判定と指示の提示までで止め、発注はユーザー本人が手動で行う。
  証券会社サイト・取引アプリへのログイン・操作は一切しない。
- 本システムは試験運転中。新規建ての通知文には必ず「（試験運転）」を付ける。
- 新規建ては必ず「成行 → 決済OCO（逆指値＋目標利確指値）」をセットで指示する。
  利確指値の欠落は禁止（2026-08-13ユーザー指示）。
- 本出力はバックアップ。Mac側の毎時配信が動いている場合はそちらが正。

```python
# -*- coding: utf-8 -*-
"""FXドル円 第4システム「デイトレ15分」— クラウド単独実行版（Mac不要・依存ライブラリ不要）

名称は「15分」だが、2026-08-13の日次研究で採用された現行戦略の実体は
**1時間足ドンチャン24/12・フィルタ無**（研究が15分/1時間/4時間を横断探索した結果）。
Mac側エンジン(intraday15_engine.py)と同じ判定を、公開データだけで再現する。

パラメータはMacのconfig.jsonの「デイトレ15分」と同期させること。
"""
import json
import urllib.request
from datetime import datetime, timedelta, timezone

# ==== パラメータ（Mac config.jsonの「デイトレ15分」と同期） ====
TF_MIN = 60                 # 執行時間足（分）。現行は60＝1時間足
ENTRY_N, EXIT_N = 24, 12    # ドンチャン期間
ATR_K, TP_K = 3.0, 6.0      # ストップ/利確のATR係数
RISK, LEV = 0.003, 1.5
EQUITY, LOT = 1_000_000, 1000
TRAIL_NOTIFY_ATR = 1.0      # トレイル更新の量子化（Mac 15分エンジンと同一。2H系は0.5）
EVENT_BLOCK_MIN = 45        # ★5イベントのこの分数前から新規停止
JST = timezone(timedelta(hours=9))
# 運用開始アンカー（この時刻より前のバーでは建玉しない＝Mac実運用と同期）
ANCHOR_JST = "2026-08-13 00:00"

# ==== 状態シード（任意・精度が段違いに上がる） ====
# Mac の state_intraday15.json が読めるなら、その "state" と "last_bar" を貼る。
# 貼られていればリプレイではなく「その状態からの続き」で計算するため、
# 建値・最良値・数量がMac版と完全一致する。
SEED_AS_OF = None           # 例: "2026-08-15 06:00"（= state_intraday15.json の last_bar）
LIVE_STATE = {}             # 例: {"position": -1, "entry": 159.358, "stop": 159.863,
                            #      "tp": 158.349, "units": 5000, "best": 159.285,
                            #      "entry_date": "2026-08-15 03:00"}

STAR5 = ["non-farm", "average hourly earnings", "fomc",
         "federal funds rate", "cpi", "boj", "monetary policy"]


def http_json(url):
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.loads(r.read().decode())


def fetch_1h():
    """Yahoo 1時間足730日（確定バーのみ）。"""
    d = http_json("https://query1.finance.yahoo.com/v8/finance/chart/"
                  "USDJPY=X?range=730d&interval=1h")["chart"]["result"][0]
    q = d["indicators"]["quote"][0]
    now = datetime.now(timezone.utc).timestamp()
    return [(t, o, h, lo, c) for t, o, h, lo, c in zip(
        d["timestamp"], q["open"], q["high"], q["low"], q["close"])
        if None not in (o, h, lo, c) and t + 3600 <= now]


def agg_bars(bars1h, minutes):
    """1時間足→N分足（UTC固定グリッド）。末尾の未完成ビンは捨てる。
    TF_MIN=60 なら素通し。Macは15分足を60分へリサンプルするが、
    UTC時グリッドで揃うためYahooの1時間足と一致する。"""
    if minutes == 60:
        return list(bars1h)
    if minutes < 60:
        raise SystemExit("60分未満の時間足はYahoo 1時間足からは再現できない。"
                         "Mac版（15分足取得）を使うこと")
    sec = minutes * 60
    agg = {}
    for t, o, h, lo, c in bars1h:
        k = t // sec * sec
        if k not in agg:
            agg[k] = [o, h, lo, c]
        else:
            a = agg[k]
            a[1] = max(a[1], h)
            a[2] = min(a[2], lo)
            a[3] = c
    out = sorted((k, *v) for k, v in agg.items())
    if out and out[-1][0] + sec > bars1h[-1][0] + 3600:
        out = out[:-1]
    return out


def atr_series(bars, n=14):
    """Wilder型ATR（ewm alpha=1/n, adjust=False）— Mac backtest.atrと同一。"""
    out, prev_c, a = [], None, None
    for _, o, h, lo, c in bars:
        tr = h - lo if prev_c is None else max(h - lo, abs(h - prev_c),
                                               abs(lo - prev_c))
        a = tr if a is None else a + (tr - a) / n
        out.append(a)
        prev_c = c
    return out


def donchian_series(bars):
    """Mac strategies_15m.donchian_15m（フィルタ無）と同一。
    shift(1)＝前バーまでのレンジ対当バー終値。"""
    sig = [0] * len(bars)
    pos = 0
    for i in range(len(bars)):
        if i < ENTRY_N or i < EXIT_N:
            continue
        c = bars[i][4]
        hi = max(b[2] for b in bars[i - ENTRY_N:i])
        lo = min(b[3] for b in bars[i - ENTRY_N:i])
        ehi = max(b[2] for b in bars[i - EXIT_N:i])
        elo = min(b[3] for b in bars[i - EXIT_N:i])
        if pos == 0:
            if c > hi:
                pos = 1
            elif c < lo:
                pos = -1
        elif pos == 1 and c < elo:
            pos = -1 if c < lo else 0
        elif pos == -1 and c > ehi:
            pos = 1 if c > hi else 0
        sig[i] = pos
    return sig


def replay(bars, atr, sig):
    """Mac intraday15_engine と同じ順序でリプレイする。
    ①ストップ到達（確定バー高安・ストップ優先）→②利確到達→③シグナル差分で
    決済/新規（entry=close・ATR×3ストップ・ATR×6利確）→④同方向継続なら
    トレイル（best基準・単調・ATR×1.0以上の改善のみ反映＝Macの量子化と同一）。"""
    anchor = datetime.strptime(ANCHOR_JST, "%Y-%m-%d %H:%M") \
        .replace(tzinfo=JST).timestamp() - TF_MIN * 60
    pos, st, last_event = 0, {}, "待機"
    start = anchor
    seed = LIVE_STATE if (SEED_AS_OF and LIVE_STATE.get("position")) else None
    if seed:
        pos = int(seed["position"])
        st = {"entry": float(seed["entry"]), "best": float(seed["best"]),
              "units": int(seed["units"]), "stop": float(seed["stop"]),
              "tp": float(seed["tp"]) if seed.get("tp") else None,
              "entry_time": seed.get("entry_date", "")}
        last_event = "シード継続"
        start = datetime.strptime(SEED_AS_OF, "%Y-%m-%d %H:%M") \
            .replace(tzinfo=JST).timestamp() - TF_MIN * 60

    for i in range(len(bars)):
        t, o, h, lo_, c = bars[i]
        if sig[i] == 0 and i < ENTRY_N:
            continue
        if t < start or (seed and t <= start):
            continue
        a = atr[i]
        # ①ストップ →②利確（ストップ優先）
        if pos != 0:
            if (pos > 0 and lo_ <= st["stop"]) or (pos < 0 and h >= st["stop"]):
                pos, st, last_event = 0, {}, "ストップ決済"
            elif st.get("tp") and ((pos > 0 and h >= st["tp"])
                                   or (pos < 0 and lo_ <= st["tp"])):
                pos, st, last_event = 0, {}, "利確決済"
        # ③シグナル差分
        if sig[i] != pos:
            pos = sig[i]
            if pos != 0:
                stop_dist = ATR_K * a
                units = int(min(EQUITY * RISK / stop_dist,
                                EQUITY * LEV / c) // LOT * LOT)
                st = {"entry": c, "best": c, "units": units,
                      "stop": round(c - pos * stop_dist, 3),
                      "tp": round(c + pos * TP_K * a, 3) if TP_K else None,
                      "entry_time": datetime.fromtimestamp(
                          t + TF_MIN * 60, JST).strftime("%Y-%m-%d %H:%M"),
                      "atr0": a}
                last_event = "新規" + ("買" if pos > 0 else "売")
            else:
                st, last_event = {}, "シグナル決済"
        elif pos != 0:
            # ④トレイル（ATR×TRAIL_NOTIFY_ATR以上の改善のみ反映）
            st["best"] = max(st["best"], c) if pos > 0 else min(st["best"], c)
            cand = st["best"] - pos * ATR_K * a
            if (cand - st["stop"]) * pos >= TRAIL_NOTIFY_ATR * a:
                st["stop"] = round(cand, 3)
    return pos, st, last_event


def _feed(url):
    """Forex Factoryフィードを3時間キャッシュ付きで取る。

    ★2026-08-16 追加: キャッシュ無しで毎回叩くと配信元が HTTP 429 を返し、
    「カレンダー取得失敗」が常態化する（実測で確認）。Mac側 events.py と同じく
    3時間以内は再取得せず、取得失敗時は72時間以内の古いキャッシュで代替する。"""
    import hashlib
    import os
    d = os.path.join(os.path.expanduser("~"), ".fx_ff_cache")
    p = os.path.join(d, hashlib.md5(url.encode()).hexdigest() + ".json")

    def read(max_age_h):
        # 保存形式は Mac events.py と同じ {"fetched": iso, "data": [...]}。
        # Macの results/cache/*.json をそのままコピーして使える。
        try:
            with open(p, encoding="utf-8") as f:
                obj = json.load(f)
            if isinstance(obj, list):          # 旧形式（生配列）も受ける
                obj = {"fetched": None, "data": obj}
            age = (datetime.now(timezone.utc)
                   - datetime.fromisoformat(obj["fetched"])).total_seconds() \
                if obj.get("fetched") else \
                datetime.now().timestamp() - os.path.getmtime(p)
            return obj["data"] if age <= max_age_h * 3600 else None
        except Exception:
            return None

    fresh = read(3)
    if fresh is not None:
        return fresh
    try:
        data = http_json(url)
        os.makedirs(d, exist_ok=True)
        with open(p, "w", encoding="utf-8") as f:
            json.dump({"fetched": datetime.now(timezone.utc).isoformat(),
                       "data": data}, f)
        return data
    except Exception:
        return read(72)


def events_24h():
    ev, ok = [], False
    now = datetime.now(timezone.utc)
    for u in ("https://nfs.faireconomy.media/ff_calendar_thisweek.json",
              "https://nfs.faireconomy.media/ff_calendar_nextweek.json"):
        data = _feed(u)
        if data is None:
            continue
        ok = True
        for e in data:
            if e.get("impact") != "High" or e.get("country") not in ("USD", "JPY"):
                continue
            if not any(p in e.get("title", "").lower() for p in STAR5):
                continue
            try:
                dt = datetime.fromisoformat(e["date"])
            except (KeyError, ValueError):
                continue
            if now <= dt <= now + timedelta(hours=24):
                ev.append((dt, e["country"], e.get("title", "")))
    return (sorted(set(ev)) if ok else None)


def main():
    bars1h = fetch_1h()
    bars = agg_bars(bars1h, TF_MIN)
    atr = atr_series(bars)
    sig = donchian_series(bars)
    pos, st, last_event = replay(bars, atr, sig)
    t, o, h, lo_, c = bars[-1]
    a = atr[-1]
    bar_jst = datetime.fromtimestamp(t + TF_MIN * 60, JST)
    now = datetime.now(JST)

    # データ鮮度ガード（Mac intraday15_engine と同一の考え方）。
    # Yahoo障害・レート制限中に過去のブレイクを「今のシグナル」として通知する
    # 事故を防ぐ。閾値 = 時間足の2本分+30分。週末・祝日の休場中は必ずここに
    # 該当するが、それは正常（新規判定を出さないだけ）。
    age_min = (now.timestamp() - (t + TF_MIN * 60)) / 60
    stale = age_min > TF_MIN * 2 + 30

    ev = events_24h()
    soon = [] if ev is None else \
        [e for e in ev if (e[0] - datetime.now(timezone.utc)).total_seconds()
         <= EVENT_BLOCK_MIN * 60]

    L = [f"■ ドル円 デイトレ15分指示書【クラウド代行】 {now:%Y-%m-%d %H:%M}"
         "【試験運転】",
         f"  確定バー: {bar_jst:%Y-%m-%d %H:%M}（{TF_MIN}分足）"
         f"  終値: {c:.3f}円  ATR(14): {a:.3f}円",
         "-" * 46,
         f"▼ デイトレ15分（{TF_MIN}分足ドンチャン{ENTRY_N}/{EXIT_N}・フィルタ無"
         f"・ATR×{ATR_K}・利確ATR×{TP_K}・リスク{RISK:.1%}）"]

    if stale:
        L.append(f"⚠データ鮮度不足: 最終確定バーが{age_min:.0f}分前。"
                 f"新規判定は見送る（休場中なら正常。平日ならYahoo障害/"
                 f"レート制限を疑う）。以下の現況は参考値。")

    if pos != 0:
        L += [f"【現況】{'買' if pos > 0 else '売'} {st['units']:,}通貨 保有"
              f"（{st['entry_time']}バー建て・建値{st['entry']:.3f}円）",
              f"  決済逆指値: {st['stop']:.3f}円（トレイリング）",
              f"  目標利確指値: {st['tp']:.3f}円（建玉時固定・トレイルしない）",
              "  → 口座の建玉・OCOが上記と一致しているか確認。"
              "乖離があれば上記へ合わせる。"]
    else:
        L += [f"【待機】ノーポジ（直近イベント: {last_event}）。",
              "  → 口座にデイトレ15分枠の建玉が残っていれば、直近イベントに"
              "従い決済済みか確認。新規は次バー確定時に再判定。"]
        if last_event in ("ストップ決済", "利確決済"):
            L.append(f"  ※直近で{last_event}が発生した可能性。"
                     "MATRIX TRADERの約定履歴を確認すること。")
        if sig[-1] != 0 and soon:
            L.append(f"  ※新規{'買' if sig[-1] > 0 else '売'}シグナルありだが"
                     f"★5指標直前のため見送り中。")

    L += ["", f"◆ 指標イベント（★5級のみ・{EVENT_BLOCK_MIN}分前から新規停止）"]
    if ev is None:
        L.append("  カレンダー取得失敗。FOMC・雇用統計・日銀等を手動確認推奨")
    elif ev:
        for dt, cur, title in ev:
            mark = " ★直前=新規見送り" if (dt, cur, title) in soon else ""
            L.append(f"  ・{dt.astimezone(JST):%m/%d %H:%M} [{cur}] {title}{mark}")
    else:
        L.append("  今後24時間: なし")

    L += ["-" * 46,
          "※発注はMATRIX TRADERで本人が手動で行うこと(JFXはEA等の自動発注禁止)。",
          "※新規は必ず成行→決済OCO（逆指値＋目標利確指値）をセットで置くこと。",
          "※本書はクラウド代行版。Mac側の毎時配信が動いていればそちらが正。"]
    print("\n".join(L))
    print(json.dumps({"pos": pos, "state": st, "last_event": last_event,
                      "close": round(c, 3), "atr": round(a, 3),
                      "signal": sig[-1], "event_block": bool(soon),
                      "stale": stale, "bar_age_min": round(age_min)},
                     ensure_ascii=False))


if __name__ == "__main__":
    main()
```

## 保守（重要）

- **パラメータ同期**: 日次研究（`research_15m.py`）が進化を採用したら、スクリプト冒頭の
  `TF_MIN` / `ENTRY_N` / `EXIT_N` / `ATR_K` / `TP_K` / `RISK` を `config.json` の
  「デイトレ15分」に合わせて更新する。`パラメータ.時間足分` が60未満になった場合は
  本スクリプトでは代替できない（前述）。
- **シード同期**: `state_intraday15.json` が更新されたら `LIVE_STATE` と `SEED_AS_OF` を貼り替える。
- **トレイルの量子化**: 本システムは `TRAIL_NOTIFY_ATR = 1.0`（第3システムの2H系は0.5）。
  ATR×1.0以上の改善があった時だけ逆指値を動かす＝Macエンジンと同一。
- **メール配信**: Mac版はシグナル発生時にエンジン自身が macOS通知＋即時メール
  （（本人アドレス・local_settings.json で設定） 宛・Gmail SMTP）を送る。クラウド版にはこの経路が無いので、
  プッシュ通知が唯一の到達手段になる。**通知を落とさないこと。**
- **利確はトレイルしない**: 逆指値だけがトレイルし、目標利確指値は建玉時の値のまま固定。
  この非対称性は設計どおりで、変更してはいけない。
